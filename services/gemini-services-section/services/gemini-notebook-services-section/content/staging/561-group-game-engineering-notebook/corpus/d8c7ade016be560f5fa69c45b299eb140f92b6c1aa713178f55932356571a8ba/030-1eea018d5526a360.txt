# @561-group/math/dgen

**The d-frame `H¹`-generator `D_μ` at each non-Scott-continuous firing — on `@561-group/math/{dframe,verdier,obstruction}`.**

`obstruction` shows `H¹` is generated by the firings at **limit** (non-Scott-continuous) stages; `dframe` splits the substitution case into truth/falsity sides.
This package gives the **general** settling its per-firing d-frame generators: at each firing `μ`, the firing cell's bilattice value fixes a generator

```
D_μ = (L₊, L₋, con, tot) ∈ dFrm
```

and the d-frame cohomology is the direct sum `H¹_dFrm = ⊕_μ D_μ`.
Its abelian shadow `S(⊕ D_μ) = (ℤ^{#truth+⊤}, ℤ^{#falsity+⊤})` recovers the `dframe` rank counts, but the d-frame keeps the per-firing consistency/totality the shadow throws away (notably the `⊤`-firing's con-failure, a paraconsistent witness).
Built straight to the proved corpus theorem `d-frame-h1-generator-at-nsc-firing.md`.

```js
import { fromSettling, h1Dframe } from "@561-group/math/dgen";
import { settling } from "@561-group/math/obstruction/settling";

const v = settling([{ designated: [] }, { designated: ["a"], limit: true }]);
h1Dframe(fromSettling(v, ["top"]));   // → { rank: 1, structure: "D_1", ... }
```
