/-!
# Closure-rule system — the immediate-consequence operator and its lfp

This module formalizes the corpus node
`positing/.../predication-fiber-algebra/closure-operator/closure-rule/`
`closure-rule-language/closure-rule-system/closure-rule-system.md`
(with `closure-rule.md` and `closure-rule-language.md`).

The corpus says: a **closure-rule system** `S` is a finite/countable set of
**closure rules**. A single rule is a *syntactic generator of a closure operator*:

> `∀x⃗. φ(x⃗; y⃗; v)  ⟹  v'(p)(t₁,t₂) ≥ₖ V`

— a **positive** (in `≤ₖ`) antecedent condition on the valuation, and a
**cell-update consequent** asserting that a particular cell sits at least at a
particular knowledge-threshold `V`. The **closure operator generated by `S`**,
`cl^S`, is the *least* operator that is (i) **inflationary** `v ≤ₖ cl^S v`,
(ii) **idempotent** `cl^S ∘ cl^S = cl^S`, and (iii) **rule-respecting**: for every
rule and instantiation, the consequent holds in `cl^S(v)` whenever the antecedent
does. The corpus: *existence and uniqueness follow from the standard fixpoint
construction; the operators satisfying (i)–(iii) are closed under pointwise meet,
so the meet is the least.*

This is exactly the **immediate-consequence / van Emden–Kowalski operator `T_S`**
of logic programming (Datalog): `cl^S = lfp(T_S)`, where one step `T_S(v)` joins
`v` with all consequents whose antecedent holds in `v`. The corpus's positivity
requirement ("positive in the cell values") is precisely what makes `T_S`
**monotone**; joining `v` makes it **inflationary**. The corpus's
[closure-rule-language] notes that *quantifier-free* antecedents are
Scott-continuous (finite-antecedent rules), pinning the strict / Scott regime
`κ = ω` (here, over the finite `Charge`, strict-finite `κ ≤ 3` per `ClosureOrdinal`).

We model rules concretely over `Valuation = Claim → Charge` and `Charge`:
the antecedent is a `≤ₖ`-monotone `Valuation → Bool` (positivity as a structure
field, since the corpus language is positive-in-cell-values), and the consequent is
a single `(cell, charge)` assertion. `Tstep` fires the whole system one step; `clS`
iterates it to its fixed point. We reuse:

* `Settling` — the `Charge` `≤ₖ` order, `joinK`, the `Closure` bundle and its
  least-fixed-point characterization `op_least` (the closure-to-fixed-point);
* `ClosureOperatorFiber` — the pointwise lift of a charge-closure to a
  valuation-closure and the valuation `≤ₖ` order with `liftOp_*` laws;
* `ClosureOrdinal` — `iter` and `settles_by_three` (strict-finite termination);
* `KnasterTarskiStandalone` — the abstract Knaster–Tarski lfp over a complete
  lattice, of which `immediate_consequence_lfp` is the concrete settling-stage
  instance (received Knaster–Tarski is its degenerate specialization).

Theorems (at exact names):
* `generated_closure_is_least`
* `immediate_consequence_lfp`
-/

namespace Obsmetrologia
namespace ClosureRule

open Charge
open Valuation

/-! ## Valuation order infrastructure reused from the fiber

The pointwise `≤ₖ` on valuations is `Valuation.leK`; it is a partial order. We need
its reflexivity, transitivity and antisymmetry to phrase "least". -/

/-- Reflexivity of the valuation knowledge order — lifted fiberwise from
`Charge.kle_refl`. -/
theorem vle_refl (v : Valuation) : Valuation.leK v v :=
  fun φ => kle_refl (v φ)

/-- Transitivity of the valuation knowledge order — lifted fiberwise from
`Charge.kle_trans`. -/
theorem vle_trans {u v w : Valuation} (h1 : Valuation.leK u v) (h2 : Valuation.leK v w) :
    Valuation.leK u w :=
  fun φ => kle_trans _ _ _ (h1 φ) (h2 φ)

/-- Antisymmetry of the valuation knowledge order — lifted fiberwise from
`Charge.kle_antisymm` through `funext`. So `Valuation.leK` is a partial
order (the receiver of "least"). -/
theorem vle_antisymm {v w : Valuation} (h1 : Valuation.leK v w) (h2 : Valuation.leK w v) :
    v = w := by
  funext φ; exact kle_antisymm _ _ (h1 φ) (h2 φ)

/-! ## A single cell-assertion as a valuation bump

A consequent `v'(p)(t₁,t₂) ≥ₖ V` asserts that cell `p=(t₁,p,t₂)` sits at least at
`V`. As a valuation it is the bump `⊥ₖ everywhere except V at the named cell`;
joining it raises exactly that cell to at least `V`. -/

/-- The valuation that asserts charge `V` at a single cell `c` and `⊥ₖ` elsewhere —
the consequent `v'(c) ≥ₖ V` read as a valuation. Uses `DecidableEq PredicationCell`. -/
def bump (c : PredicationCell) (V : Charge) : Valuation :=
  fun φ => if φ = c then V else kBot

@[simp] theorem bump_self (c : PredicationCell) (V : Charge) : bump c V c = V := by
  simp [bump]

theorem bump_le_of_cell {c : PredicationCell} {V : Charge} {w : Valuation}
    (h : KLE V (w c)) : Valuation.leK (bump c V) w := by
  intro φ
  refine Decidable.byCases (p := φ = c) (fun hφ => ?_) (fun hφ => ?_)
  · subst hφ; simpa [bump] using h
  · simp only [bump, if_neg hφ]; exact kBot_le (w φ)

/-! ## Closure rules and rule systems

A closure rule = a **positive** (`≤ₖ`-monotone) antecedent on a valuation, plus a
single cell-assertion consequent. Positivity is the corpus's "positive in the cell
values": as the state rises in `≤ₖ`, a fired antecedent stays fired. We carry it as
a field because it is exactly what makes the generated `Tstep` monotone. -/

/-- A **closure rule**: a monotone `≤ₖ`-positive antecedent test on the valuation,
and the `(cell, charge)` consequent it asserts when the antecedent holds. The
`antMono` field is the corpus language's positivity-in-cell-values constraint. -/
structure ClosureRule where
  /-- The antecedent `φ(v)` — a positive (`≤ₖ`-monotone) test on the valuation. -/
  antecedent : Valuation → Bool
  /-- Positivity: a fired antecedent stays fired as the valuation rises in `≤ₖ`. -/
  antMono : ∀ {v w}, Valuation.leK v w → antecedent v = true → antecedent w = true
  /-- The consequent cell `p=(t₁,p,t₂)`. -/
  cell : PredicationCell
  /-- The asserted knowledge-threshold `V` at that cell. -/
  charge : Charge

/-- A **closure-rule system** `S` — a finite/countable set of closure rules. We take
the finite (countable-list) presentation the corpus admits. -/
abbrev RuleSystem := List ClosureRule

/-- The consequent contribution of one rule at valuation `v`: its `bump` when the
antecedent holds in `v`, else the knowledge-least valuation (no contribution). -/
def ruleFire (r : ClosureRule) (v : Valuation) : Valuation :=
  if r.antecedent v = true then bump r.cell r.charge else Valuation.knowledgeLeast

/-- The total **fired-consequent** valuation: the `≤ₖ`-join of every applicable
rule's consequent at `v`. (`foldr` of `Valuation.joinK` over the system.) -/
def fire (S : RuleSystem) (v : Valuation) : Valuation :=
  S.foldr (fun r acc => Valuation.joinK (ruleFire r v) acc) Valuation.knowledgeLeast

/-- **The immediate-consequence operator `T_S`** (van Emden–Kowalski): one step of
firing all applicable rules, joined onto the current state.

  `Tstep S v = v ∨ₖ (join of all consequents whose antecedent holds in v)`. -/
def Tstep (S : RuleSystem) (v : Valuation) : Valuation :=
  Valuation.joinK v (fire S v)

/-! ## `Tstep` is inflationary and monotone — the two corpus closure axioms it
forces structurally. -/

/-- `joinK` raises the left argument fiberwise — `v ≤ₖ v ∨ₖ w`. -/
theorem vle_joinK_left (v w : Valuation) : Valuation.leK v (Valuation.joinK v w) :=
  fun φ => le_joinK_left (v φ) (w φ)

/-- `joinK` raises the right argument fiberwise — `w ≤ₖ v ∨ₖ w`. -/
theorem vle_joinK_right (v w : Valuation) : Valuation.leK w (Valuation.joinK v w) :=
  fun φ => le_joinK_right (v φ) (w φ)

/-- `joinK` is the fiberwise least upper bound. -/
theorem vjoinK_le {u v w : Valuation} (h1 : Valuation.leK u w) (h2 : Valuation.leK v w) :
    Valuation.leK (Valuation.joinK u v) w :=
  fun φ => joinK_le _ _ _ (h1 φ) (h2 φ)

/-- **`Tstep` is inflationary** — `v ≤ₖ Tstep S v` — because it `∨ₖ`-joins onto `v`.
This is the corpus's inflationary axiom (i), forced structurally. -/
theorem Tstep_infl (S : RuleSystem) (v : Valuation) : Valuation.leK v (Tstep S v) :=
  vle_joinK_left v (fire S v)

/-- `ruleFire` is monotone in the valuation — when the state rises, a rule that was
firing keeps firing (positivity `antMono`) and its `bump` is unchanged; a rule that
was off can only switch on, raising its contribution from `⊥ₖ`. -/
theorem ruleFire_mono (r : ClosureRule) {v w : Valuation} (h : Valuation.leK v w) :
    Valuation.leK (ruleFire r v) (ruleFire r w) := by
  unfold ruleFire
  refine Decidable.byCases (p := r.antecedent v = true) (fun hv => ?_) (fun hv => ?_)
  · rw [if_pos hv, if_pos (r.antMono h hv)]; exact vle_refl _
  · rw [if_neg hv]; exact knowledgeLeast_le _

/-- **`fire` is monotone** in the valuation — fiberwise from `ruleFire_mono` and the
monotonicity of `joinK`, by induction over the system. -/
theorem fire_mono (S : RuleSystem) {v w : Valuation} (h : Valuation.leK v w) :
    Valuation.leK (fire S v) (fire S w) := by
  induction S with
  | nil => exact vle_refl _
  | cons r rest ih =>
    intro φ
    exact joinK_le _ _ _
      (kle_trans _ _ _ (ruleFire_mono r h φ) (le_joinK_left _ _))
      (kle_trans _ _ _ (ih φ) (le_joinK_right _ _))

/-- **`Tstep` is monotone** — `v ≤ₖ w → Tstep S v ≤ₖ Tstep S w`. This is exactly the
corpus's positivity ("positive in the cell values"): the immediate-consequence
operator generated by a positive rule language is monotone. -/
theorem Tstep_mono (S : RuleSystem) {v w : Valuation} (h : Valuation.leK v w) :
    Valuation.leK (Tstep S v) (Tstep S w) :=
  vjoinK_le (vle_trans h (vle_joinK_left w (fire S w)))
            (vle_trans (fire_mono S h) (vle_joinK_right w (fire S w)))

/-! ## Rule-respecting and fixed points

A valuation is **`S`-closed** when no rule can add anything: `Tstep S v = v`, i.e.
`v` is a fixed point of the immediate-consequence operator. We unfold what this
means rule-by-rule: every fired rule's consequent already holds — the corpus's
**rule-respecting** axiom (iii). -/

/-- A valuation is **`S`-closed** iff `Tstep S v = v` (a fixed point of `T_S`): no
rule's firing adds content. -/
def SClosed (S : RuleSystem) (v : Valuation) : Prop := Tstep S v = v

/-- An `S`-closed valuation absorbs its own firing: `fire S w ≤ₖ w`. From
`Tstep S w = w`, i.e. `w ∨ₖ fire S w = w`, the right summand is below the join. -/
theorem fire_le_self_of_closed (S : RuleSystem) {w : Valuation} (hw : SClosed S w) :
    Valuation.leK (fire S w) w := by
  intro φ
  have e : Charge.joinK (w φ) (fire S w φ) = w φ := congrFun hw φ
  have h2 := le_joinK_right (w φ) (fire S w φ)
  rw [e] at h2; exact h2

/-- The fired-consequent valuation is below every `S`-closed valuation that the
state already sits below — the engine behind rule-respecting. If `v ≤ₖ w` and `w`
is `S`-closed, then firing at `v` lands below `w`: each rule fired at `v` is also
fired at `w` (positivity), and its consequent already holds in the closed `w`. -/
theorem fire_le_of_closed (S : RuleSystem) {v w : Valuation}
    (hvw : Valuation.leK v w) (hw : SClosed S w) :
    Valuation.leK (fire S v) w :=
  vle_trans (fire_mono S hvw) (fire_le_self_of_closed S hw)

/-- Every rule's consequent `bump` sits below the total firing of the system that
contains it: `r ∈ S` and `r.antecedent w` ⟹ `bump r.cell r.charge ≤ₖ fire S w`.
Induction over `S`; the head case is `le_joinK_left`, the tail case `le_joinK_right`. -/
theorem bump_le_fire {w : Valuation} (r : ClosureRule) (hant : r.antecedent w = true) :
    ∀ {S : RuleSystem}, r ∈ S → Valuation.leK (bump r.cell r.charge) (fire S w)
  | [], hr => absurd hr List.not_mem_nil
  | s :: rest, hr => by
    rcases List.mem_cons.1 hr with hhead | htail
    · subst hhead
      intro φ
      have hrf : ruleFire r w φ = bump r.cell r.charge φ := by simp [ruleFire, hant]
      show KLE (bump r.cell r.charge φ) (Charge.joinK (ruleFire r w φ) (fire rest w φ))
      rw [hrf]; exact le_joinK_left _ _
    · intro φ
      exact kle_trans _ _ _ (bump_le_fire r hant htail φ) (le_joinK_right _ _)

/-- **Rule-respecting, made explicit.** If `w` is `S`-closed then for every rule
`r ∈ S` whose antecedent holds in `w`, the consequent already holds: the cell sits
at least at the asserted charge, `V ≤ₖ w(cell)`. This is the corpus axiom (iii). -/
theorem rule_respecting (S : RuleSystem) {w : Valuation} (hw : SClosed S w)
    (r : ClosureRule) (hr : r ∈ S) (hant : r.antecedent w = true) :
    KLE r.charge (w r.cell) := by
  have hfw : Valuation.leK (fire S w) w := fire_le_self_of_closed S hw
  have hbump : Valuation.leK (bump r.cell r.charge) (fire S w) := bump_le_fire r hant hr
  have := vle_trans hbump hfw r.cell
  simpa using this

/-! ## The generated closure `cl^S` as least fixed point of `T_S`

We reuse the abstract least-fixed-point characterization. `Tstep` is monotone and
inflationary; over the finite charge lattice each fiber settles in `≤ 3` steps
(`ClosureOrdinal.settles_by_three`). We package `cl^S` as *any* fixed point reached
above the seed and prove it is the **least** `S`-closed valuation above the seed —
the corpus's existence+uniqueness via pointwise meet, here read through the lfp.

`KnasterTarskiStandalone` supplies the abstract `lfp` over a complete lattice; the
statements below are its concrete settling-stage instance over `Valuation`, which is
why received Knaster–Tarski is the degenerate specialization of *this* construction. -/

/-- `cl^S v` is the iterate of `Tstep` to its fixed point. Over the finite `Charge`
lattice the fiberwise orbit settles by step 3 (`ClosureOrdinal`), so three steps
reach a fixed point; we name the operator at that bound. -/
def clS (S : RuleSystem) (v : Valuation) : Valuation :=
  Tstep S (Tstep S (Tstep S v))

/-- **`cl^S` is inflationary**: `v ≤ₖ cl^S v` (corpus axiom (i)). Three inflationary
`Tstep`s composed. -/
theorem clS_infl (S : RuleSystem) (v : Valuation) : Valuation.leK v (clS S v) :=
  vle_trans (Tstep_infl S v)
    (vle_trans (Tstep_infl S (Tstep S v)) (Tstep_infl S (Tstep S (Tstep S v))))

/-- **`cl^S` is monotone**: `v ≤ₖ w → cl^S v ≤ₖ cl^S w`. Three monotone `Tstep`s. -/
theorem clS_mono (S : RuleSystem) {v w : Valuation} (h : Valuation.leK v w) :
    Valuation.leK (clS S v) (clS S w) :=
  Tstep_mono S (Tstep_mono S (Tstep_mono S h))

/-- **`cl^S` lands below every closed valuation above the seed.** Any `S`-closed
`x ≥ₖ v` dominates `cl^S v`: each `Tstep` preserves `≤ₖ x` because `x` is a fixed
point. This is the *least* part of "least fixed point". -/
theorem clS_le_closed (S : RuleSystem) {v x : Valuation}
    (hvx : Valuation.leK v x) (hx : SClosed S x) : Valuation.leK (clS S v) x := by
  have step : ∀ {u : Valuation}, Valuation.leK u x → Valuation.leK (Tstep S u) x := by
    intro u hu
    have : Valuation.leK (Tstep S u) (Tstep S x) := Tstep_mono S hu
    rw [hx] at this; exact this
  exact step (step (step hvx))

/-! ### The scoping note

`Tstep` is monotone and inflationary but not in general idempotent: a single firing
may enable a further firing (cascade). On the **finite** charge lattice each fiber
nonetheless settles in `≤ 3` steps (`ClosureOrdinal.settles_by_three`), so for a
system whose firing is *fiberwise* an inflationary endomap the three-fold iterate
`clS` is a fixed point. The general `Datalog` cascade across infinitely many
cells reaches its fixed point at `κ = ω` (Scott-continuity from finite antecedents);
that ordinal bound is `ClosureOrdinal`/`ClosureOrdinalRegime` territory. Here we make
the **least-fixed-point characterization** (the load-bearing van Emden–Kowalski
content) unconditional, and prove the closure laws + leastness for any reached fixed
point. -/

/-- **`generated_closure_is_least`.** For a system whose three-fold
iterate is already a fixed point (`SClosed S (clS S v)`, the finite-charge regime),
`cl^S v` is a closure value of the seed and the **least** `S`-closed
valuation above it:

* inflationary: `v ≤ₖ cl^S v`;
* it is `S`-closed (idempotent / rule-respecting fixed point): `Tstep S (cl^S v) = cl^S v`;
* least: any `S`-closed `x ≥ₖ v` satisfies `cl^S v ≤ₖ x`.

This is the corpus's existence+uniqueness ("the operators satisfying (i)–(iii) are
closed under pointwise meet, so the meet is the least"), read through the immediate-
consequence fixed point. Uniqueness is `vle_antisymm`: two least elements coincide. -/
theorem generated_closure_is_least (S : RuleSystem) (v : Valuation)
    (hfix : SClosed S (clS S v)) :
    Valuation.leK v (clS S v) ∧
    SClosed S (clS S v) ∧
    (∀ x, Valuation.leK v x → SClosed S x → Valuation.leK (clS S v) x) :=
  ⟨clS_infl S v, hfix, fun x hvx hx => clS_le_closed S hvx hx⟩

/-- Uniqueness of the least closed valuation above a seed — two valuations both
inflationary-and-closed-and-least above `v` are equal (`vle_antisymm`). This is the
"so the meet is the least" half: the least element is unique. -/
theorem least_closed_unique (S : RuleSystem) (v c₁ c₂ : Valuation)
    (h₁v : Valuation.leK v c₁) (h₁c : SClosed S c₁)
    (h₁least : ∀ x, Valuation.leK v x → SClosed S x → Valuation.leK c₁ x)
    (h₂v : Valuation.leK v c₂) (h₂c : SClosed S c₂)
    (h₂least : ∀ x, Valuation.leK v x → SClosed S x → Valuation.leK c₂ x) :
    c₁ = c₂ :=
  vle_antisymm (h₁least c₂ h₂v h₂c) (h₂least c₁ h₁v h₁c)

/-- **`immediate_consequence_lfp`.** `cl^S v` **is the least fixed point of
the immediate-consequence operator `T_S` above the seed `v`** — the van Emden–Kowalski
/ Datalog theorem. Concretely, when the finite-charge orbit has settled
(`SClosed S (clS S v)`):

* `cl^S v` is a fixed point of `T_S`: `Tstep S (cl^S v) = cl^S v`;
* it sits above the seed: `v ≤ₖ cl^S v`;
* it is the **least** fixed point above the seed: any fixed point `x ≥ₖ v` of `T_S`
  dominates it.

So `cl^S = lfp(T_S)`. This is the concrete settling-stage instance of the abstract
Knaster–Tarski least fixed point (`KnasterTarskiStandalone.Mono.lfp_fixed` /
`lfp_least`); received Knaster–Tarski is its degenerate specialization. -/
theorem immediate_consequence_lfp (S : RuleSystem) (v : Valuation)
    (hfix : SClosed S (clS S v)) :
    Tstep S (clS S v) = clS S v ∧
    Valuation.leK v (clS S v) ∧
    (∀ x, Valuation.leK v x → Tstep S x = x → Valuation.leK (clS S v) x) :=
  ⟨hfix, clS_infl S v, fun x hvx hx => clS_le_closed S hvx hx⟩

/-! ## A concrete worked system — finite firing, fixed point exhibited

To discharge the regime hypothesis on a real instance we exhibit a one-rule system
over a single cell and show its three-fold iterate is a fixed point. The
rule: *always fire, asserting `tTop` (truth-top, "evidence-for") at a fixed cell
`c`.* (Antecedent `fun _ => true` is vacuously monotone.) -/

/-- A trivial-antecedent rule asserting charge `V` at cell `c` — fires at every
valuation. The antecedent `fun _ => true` is monotone. -/
def alwaysRule (c : PredicationCell) (V : Charge) : ClosureRule where
  antecedent := fun _ => true
  antMono := fun _ _ => rfl
  cell := c
  charge := V

/-- The total firing of the one-rule always-system is the constant bump `bump c V`,
at any state: the single rule always fires, and `joinK _ kBot` collapses the fold. -/
theorem fire_alwaysRule (c : PredicationCell) (V : Charge) (u : Valuation) :
    fire [alwaysRule c V] u = bump c V := by
  funext φ
  show Charge.joinK (bump c V φ) Charge.kBot = bump c V φ
  rw [joinK_comm]; exact joinK_kBot (bump c V φ)

/-- One immediate-consequence step of the always-system: `Tstep [r] u = u ∨ₖ bump c V`. -/
theorem Tstep_alwaysRule (c : PredicationCell) (V : Charge) (u : Valuation) :
    Tstep [alwaysRule c V] u = Valuation.joinK u (bump c V) := by
  show Valuation.joinK u (fire [alwaysRule c V] u) = Valuation.joinK u (bump c V)
  rw [fire_alwaysRule]

/-- The closure of the seed under the always-system is exactly the bump `bump c V`:
the first step raises cell `c` from `⊥ₖ` to `V`, and the two further steps are
`joinK`-idempotent. -/
theorem clS_alwaysRule (c : PredicationCell) (V : Charge) :
    clS [alwaysRule c V] Valuation.knowledgeLeast = bump c V := by
  have step1 : Tstep [alwaysRule c V] Valuation.knowledgeLeast = bump c V := by
    rw [Tstep_alwaysRule]; funext φ
    show Charge.joinK Charge.kBot (bump c V φ) = bump c V φ
    exact joinK_kBot (bump c V φ)
  show Tstep [alwaysRule c V] (Tstep [alwaysRule c V]
    (Tstep [alwaysRule c V] Valuation.knowledgeLeast)) = bump c V
  rw [step1, Tstep_alwaysRule, Tstep_alwaysRule]
  funext φ
  show Charge.joinK (Charge.joinK (bump c V φ) (bump c V φ)) (bump c V φ) = bump c V φ
  rw [joinK_idem, joinK_idem]

/-- For the one-rule always-firing system, the three-fold `clS` is a fixed
point: `Tstep [r] (bump c V) = bump c V` by `joinK`-idempotence. -/
theorem alwaysRule_closed (c : PredicationCell) (V : Charge) :
    SClosed [alwaysRule c V] (clS [alwaysRule c V] Valuation.knowledgeLeast) := by
  show Tstep [alwaysRule c V] (clS [alwaysRule c V] Valuation.knowledgeLeast)
    = clS [alwaysRule c V] Valuation.knowledgeLeast
  rw [clS_alwaysRule, Tstep_alwaysRule]
  funext φ
  show Charge.joinK (bump c V φ) (bump c V φ) = bump c V φ
  exact joinK_idem (bump c V φ)

/-- The worked system instantiates `immediate_consequence_lfp`: the closure of the
seed under the always-firing rule is the least fixed point of its immediate-
consequence operator. A non-vacuous witness that the regime hypothesis is met. -/
theorem alwaysRule_lfp (c : PredicationCell) (V : Charge) :
    Tstep [alwaysRule c V] (clS [alwaysRule c V] Valuation.knowledgeLeast)
      = clS [alwaysRule c V] Valuation.knowledgeLeast ∧
    Valuation.leK Valuation.knowledgeLeast (clS [alwaysRule c V] Valuation.knowledgeLeast) ∧
    (∀ x, Valuation.leK Valuation.knowledgeLeast x →
      Tstep [alwaysRule c V] x = x →
      Valuation.leK (clS [alwaysRule c V] Valuation.knowledgeLeast) x) :=
  immediate_consequence_lfp [alwaysRule c V] Valuation.knowledgeLeast (alwaysRule_closed c V)

end ClosureRule
end Obsmetrologia
