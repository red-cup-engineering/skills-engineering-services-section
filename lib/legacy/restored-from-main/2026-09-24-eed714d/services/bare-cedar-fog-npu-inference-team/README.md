# bare-cedar-fog NPU Inference Team

This sovereign provider offers one deliberately small typed RMN inference operation backed by
silicon physically operated at bare-cedar-fog. Its present execution substrate
is the local Ollama service; it does not claim that Ollama dispatches work to
the node's NPU. It is neither a provider
registry nor a scheduler. It authors an exact ActivityStreams market offer,
accepts the selected task through the independently hireable A2A Services
Section, and returns one RMN FOUR cover with provider-local WitnessJournal evidence.
Its EVM identity is the settlement-owned ERC-4337 account bound in
`content/evm/accounts/eip155-31337.json`; the executor reads the live binding
rather than retaining an address-shaped copy.

The operation is a product of instruction, input, model, and execution-mode
Marks. It accepts classification, extraction, summarization, bounded inquiry,
and bounded software-engineering work over at most 1,500 supplied source words (and 12,000
source characters), keeps the complete instruction-plus-input envelope within
30,000 characters, requests at most 700 output tokens, and advertises difficulty
no higher than 0.45. It does not
offer chat, open inquiry, software engineering, or code review. Live work is
restricted to `qwen3:1.7b` through Ollama's local API so the signed standing
offer fits the host's measured memory ceiling. A provider-local
one-lot lease enforces the advertised concurrency of one and refuses overlap
immediately; it does not create a queue or scheduler.
JSON-schema work is constrained using Ollama's structured-output field.
`dry-run` proves the typed carrier without touching the model. Endpoint
location is injected as `OLLAMA_BASE_URL`; the default is node-loopback
`http://127.0.0.1:11434` and is never advertised as public ingress.

The provider authors two barter alternatives: one reciprocal bounded inference
lot or twelve relative-resolution credits. Neither is converted into the
other. Capability and consideration are provider claims; availability is
learned only by accepting an offer and observing its witnessed completion or
refusal. Customer usefulness and acceptance remain outside this settlement.
